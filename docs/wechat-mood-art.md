# 微信与心情绘图（0.9.20）

这项功能让同一只企鹅在聊天中提出可选的图片表达：表情包、今日心情卡或小剧场配图。模型同时参考当前性格、心情与对话；原生后台执行本机绘图，文字先返回，图片完成后按消息 ID 附到对应回复。

## 使用入口

打开「和企鹅聊聊 → 表情包、心情卡与微信」。默认关闭绘图和微信，不影响已有聊天、记忆和同步。

1. 点击「安装内置绘图组件与模型」。桌宠安装独立 Python、CPU 版 PyTorch、固定版本 ComfyUI 和 DreamShaper 8 LCM 模型，显示安装进度。优先使用空闲空间充足的本机固定磁盘，组件与模型作为桌宠管理的数据文件单独保存，不写入源码仓库或塞入单个 EXE，也不修改系统 PATH/全局 Python 包。
2. 安装后点击「使用内置快速绘图」：配置按内容选择文生图或参考图生图的低步数工作流并启用绘图。桌宠在需要新图时自动启动仅监听 `127.0.0.1:8198` 的后台，空闲 5 分钟后释放进程；退出桌宠或父进程消失时停止后台。不会接管或停止已有的其他 ComfyUI 服务。图片与微信适配器需要 PATH 中的 Node.js 22.17.1 或更新版本。
3. 默认工作流使用 DreamShaper 8 LCM、512×512、8 步文生图（cfg 2），按当前对话选择普通动物、卡通脸或日常主体，不要求使用企鹅或桌宠形象。CPU 绘图速度依机器和实际负载变化，文字先返回。也可关闭「由桌宠按需管理绘图后台」，改用自己安装的本机服务（例如 `http://127.0.0.1:8188`）和可信 ComfyUI API 格式 JSON。正向提示词用 `{{prompt}}`，种子可用 `{{seed}}`。
4. 如需画桌宠本人，先上传 PNG/JPEG/WebP 角色参考图，再说「按参考图画桌宠开心的表情包」或「画你自己」。内置快速流程会读取原图、合成透明区白底、编码为 latent，并以默认 0.2 重绘强度生成；普通聊天表情仍使用原来的文生图。只对完整匹配的内置预设自动派生流程，自定义图保持原样；需要参考但图中没有 `{{image}}` 时明确提示，不会假装已经使用。图生图不是角色专属训练，外观与动作变化须看实际样图。
5. 开启本机绘图并保存；画桌宠本人或使用包含 `{{image}}` 的自定义工作流时需要参考图；上传的参考图不会被自动替换为内置素材。可以说「给我画张今日心情卡」或「画个我们一起吃小鱼的小剧场」。开启自动表达后，企鹅也可以在合适的聊天回复中提出图片。

「绘图风格与高级设置」可修改当前流程和图片风格，或选择「使用二维动漫表情风格」后保存。这个预设参考用户表情收藏中的动物题材和夸张情绪，按用户纠正统一使用二维动漫线条与平涂上色，排除立体、写实照片、塑料玩偶和 3D 渲染；聊天模型每次选一个主体和画法，不生成整张收藏拼贴。它通过文字指导文生图，不会逐张读取微信收藏、训练模型或保证复刻原图。角色参考图只用于画桌宠本人，与普通表情风格分开。

本人图还可设置独立的画风补充、避免的画风与 0.1–0.7 重绘幅度。二维角色可选择「保留二维动漫参考画风」，同时使用二维线稿/赛璐璐提示和排除立体玩偶的负面提示。默认 0.2 优先保留原图画风，动作变化较小；提高幅度更容易换画风或改动配饰。上述采样和负面参数只用于自动派生的内置参考流程，不覆盖自定义图。换参考画风或重绘参数后不会复用旧参考缓存。

ComfyUI 官方接口说明：<https://docs.comfy.org/development/comfyui-server/comms_routes>。API 客户端使用 `/upload/image`、`/prompt`、`/history/{id}` 和 `/view`。

内置安装固定 ComfyUI 0.44.0 源码提交、Python 3.13.17、CPU PyTorch 2.10.0/torchvision 0.25.0、pip 26.3 及模型修订。源码包/解释器/pip/模型通过 SHA-256 校验；其他依赖按该版 requirements 安装并记录完整 freeze，修复安装复用已记录版本。安装器只写入空目录或带桌宠所有权标记的目录。首次安装需下载数 GB；模型采用作者仓库标注的 CreativeML OpenRAIL-M，模型卡随运行时保存，ComfyUI 许可证随源码保存。模型文件校验失败时不启用运行时。未启用任意自定义节点、付费 API 节点或公网监听。

## 表达与资源规则

- 每次只处理一张图。正在绘图时仍能继续文字聊天；新的明确绘图请求会提示本次未排队。
- 自动图片默认冷却 30 分钟，滚动 24 小时最多生成 4 张新图，总自动发送（含复用）最多为新图上限的 3 倍。明确叫它画图不占自动额度。
- 优先采用模型选择的图库条目；自动表情还可以复用同心情、同性格的贴纸。参考图和自由绘图缓存分开，换参考图后不会复用旧参考图生成的图片。小剧场不按心情盲目复用，避免画面与新话题不符。
- 心情卡日期和中文配文显示在聊天界面，绘图提示词要求不生成文字，以减少乱码。
- 最多保留 40 条本机图片记录、约 100 MiB 图片。清理后旧聊天的图片可能不再显示。ComfyUI 自身的输出目录不在这项清理范围内。
- 单张参考图/输出图最多 8 MiB，工作流最多 2 MiB。超时、失败或取消均保留文字回复。取消只移除本次排队任务，不中断别的 ComfyUI 任务；已开始的计算可能继续运行。
- 保存设置会让未完成的旧设置绘图作废。图片、工作流、参考图和微信凭据只保存在本机，没有修改共享存档结构；本机缓存不会自动跨电脑同步。

## 微信

在同一设置区打开「微信私聊」并扫码。二维码由本机 QR 库生成，不使用第三方二维码服务。只回应扫码绑定主人的文字私聊，不处理群聊、其他联系人或来自消息的工具指令。

微信沿用企鹅已有的会话、记忆、性格和心情。回复文字后可以附上生成图片；不具备读取任意文件或向任意收件人发送消息的界面。授权凭据和收件处理记录通过当前 Windows 用户的 DPAPI 封装，保护失败时拒绝保存授权。

收件先保存游标和消息，再持久化认领处理；同一记录不会自动重复推理。重启后处于 processing/sending/failed/uncertain 的记录保留并显示数量，不自动重发。发送超时可能已经到达，请先核对微信实际消息，再发新消息继续。断开会清除本机授权并停止后台请求；已经发出的内容无法撤回。

协议适配参考 `xmanrui/dsh-im` 的 MIT 实现，许可证随程序放在 `wechat-LICENSE.txt`。ComfyUI 接口客户端独立实现，不需要 DSH 插件宿主。微信扫码权限和服务可用性需用实际账号验证。

## 验收范围

自动化测试覆盖本机 HTTP 出图流程、参考图上传、意图和频率策略、错误/超时/取消、微信授权校验、主人过滤、中文 UTF-8、图片加密、无自动发送重试、凭据封装和断开后旧状态回写防护。

安装、构建、模拟测试与真实出图是分别验收的项目，任务报告记录本机实际安装版本和出图结果。本机 CPU 普通猫咪表情已实际生成并按原消息附图（512×512，约 149 秒；不代表其他机器速度）。本人账号的扫码绑定与手机新文字回复已验收；微信图片真实投递尚未单独验收，自动化测试覆盖其加密与受限上传流程。图片质量仍需按实际效果确认。

微信消息编号按原始 64 位数字精确保存，避免因 JavaScript 数值舍入漏收或错误去重。旧 Node 缺少精确解析能力时会显示升级提示并保留收信游标。设置区显示最近收信时间和累计收信/接收条数；不显示消息正文、上下文令牌或授权密钥。
