# 本地保存、服务器同步与数据备份

右键企鹅 → 工具箱 → **同步与数据**。

## 本地保存

不填写服务器时，数据保存在当前 Windows 用户的本机应用目录。现有动画、音乐、拖拽、散步和窗口布局继续使用原设置。

陪伴数据包含稳定的宠物 ID、体力/饥饿/亲近度、性格、陪伴记忆、心情及变化原因、近期对话。气泡聊天、自动记忆、心情变化和主动搭话都使用这份数据；不配置服务器时也可在本机使用。

## 气泡聊天、自动记忆与主动陪伴

悬停企鹅点「聊聊」、点击说话气泡，或从右键面板点「聊聊」，即可输入文字。完整对话保存在聊天面板，较长回复在气泡中显示摘要。模型生成需要本机安装并登录 Codex，同时 PATH 中有 Node.js；沿用当前 Codex 模型配置。后台使用临时上下文，不需要在 Codex 新建可见聊天，也不会向既有工作会话发送消息。

自动记忆默认开启，只从用户明确表达的原话提取喜好、约定和近况，保存原文依据；每条消息最多提取三条。已遗忘记录继续保留删除标记。近况按鲜活度连续淡化，长期喜好和约定保持稳定。可在「记忆与主动陪伴」中关闭自动学习，或点「立即整理下一批」处理排队的消息。启动后约 15 秒开始扫描全部可读取的本机历史与归档，不按项目或日期筛掉旧聊天；后台每批最多整理八条，约每分钟一批，失败后退避五分钟。学习默认使用系统 Codex 当前的模型及账号，可单独指定整理模型。夜间、打开面板、忙碌或关闭主动搭话不会停止历史整理；关闭自动学习会保留进度并暂停历史整理，实时心情可独立开关。

历史整理按原始消息时间保存记忆，旧事实不会覆盖同属性的新记录，不把过去的近况当成今天发生；历史不累加当前心情。气泡实时互动的总心情按每条 -3 至 +3 温和变化，同时判断七维情绪，需要用户原话及解释；普通工作信息与沉默不应降低心情。总分默认按 12 小时半衰期向 70 恢复，细分情绪默认 90 分钟半衰期向零恢复。基线、下限和恢复速度可调。自动学习与心情判断依赖模型，可查看原话依据、可信度和时间线，并遗忘不准确的记忆。

主动聊天默认关闭。开启后，默认在当地时间 8–22 点、电脑空闲 90 秒至 30 分钟、未忙碌、未全屏、未开启安静模式且桌宠可见时才尝试搭话。启动前两分钟不发言；默认每次至少间隔 45 分钟，每天最多四次，不因未回应延长冷却或暂停。自动机会默认每 30 分钟本地随机判断一次，基础概率 60%，每次随机未命中下次加 10 个百分点、最多加 40。刚聊过降低概率，隔很久提高概率；参数、安静时段和起话动机均可调。打开控制面板、拖动企鹅、生成期间开始工作或用户回应，都阻止本轮自动消息。无需开启应用分类感知也能判断空闲。生成或同步失败会显示原因。

「主动搭话」页提供当前不发言原因、下一次随机机会和最近 60 条决策。**演练一次**只预览环境、动机和候选记忆，不调用模型、不发气泡；**试运行**让自动命中只记录；**真发一次**由用户手动发起，跳过自动开关、时间、概率和次数等待，仍要求不忙碌、未全屏、桌宠可见，并取得服务器预约。手动发言也更新共享发送记录，收到用户消息后取消未完成的预约。

服务器模式必须在线且本机持有活跃设备租约，先取得共享预约，再生成并复核环境，服务器确认提交后才显示气泡。有未确认的积压数据时暂缓主动发言。对话、学习结果、心情原因、冷却及每日发送次数一起同步；另一台电脑继续同一只企鹅，不会因换机重置发送次数。导入旧备份保留当前冷却状态，避免重复搭话。两台电脑须都升级到 0.9.6 或兼容新版；0.9.5 及更早版本不包含新增扩展字段。

## 与三个 DSH 插件的关系

桌宠为 Tauri / Codex 应用，当前实现独立编写，借鉴了下面三类能力，没有直接安装或完整移植 DSH 插件。不能将此版本描述为三个原插件的完整整合。

| 上游插件 | 桌宠当前适配 | 保留的宿主差异 |
| --- | --- | --- |
| [鱼的记忆](https://github.com/Yuuyuko-uu/dsh-fish-memory) | 中文词表分词、相关性评分、检索词、时间/重要度/情绪加权、连续淡化与再次提及强化、召回解释、档案预览提炼、旧版本撤销及同步 | 全部可读本机会话统一整理，不照搬 DSH 逐会话默认关闭；记忆由带原话校验的结构化结果写入 |
| [主动搭话](https://github.com/Yuuyuko-uu/dsh-speak-up) | 本地随机、未命中加成、时机因子、可调参数、演练/试运行/手动发言、决策记录和共享预约 | 使用桌宠气泡，不续写 Codex 工作会话；不套用上游提供方的峰谷价格；不因未回应减频或暂停 |
| [鱼的心情](https://github.com/Yuuyuko-uu/dsh-feiyu-mood) | 七维情绪、置信度门槛、一次性事件注入、时间线、五档心情标记、变化联动已有动作、恢复参数和同步 | 复用桌宠本体，不额外创建 DSH 挂饰窗口；甜蜜/吃醋默认关闭；整理模型可单独选，实时心情与回复共用一次推理 |

聊天面板与「同步与数据」都可进入三个标签页。记忆页可搜索、分类和按日期排序，并测试某句话会召回什么，查看选中/跳过原因、鲜活度和重要度。每轮默认最多八条、1600字，长期事实最多占三条；无相关证据时不强塞记忆。旧记忆没有扩展属性时采用兼容默认值；可用「试补旧记忆」每批提炼八条并预览后保存，也可人工编辑检索词、分类、事实键和权重。

文本档案支持 Markdown、TXT、LOG、RST、ORG，可选择文件夹向下两层；每批最多100段候选、八段模型提炼。时间默认取文中明确日期或文件修改日期，确认前可更正。只有确认后的结果写入记忆；原话及来源保留。新事实取代同属性旧事实时最多保留八个旧版本，可以逐次撤销；编辑依据已在其他设备变化时拒绝覆盖。遗忘同时清除对应元数据和旧版本，旧备份不能复活已遗忘内容。

心情判断与自动记忆可分别开关；低可信度感受留后台，达到门槛才带入回复。可以选择不影响回复、每轮提供当前状态、或新感受只带入一次，并查看实际带入原文和时间。主动开口单独标成「主动找你」，历史整理不产生当下心情。心情动作只在空闲时触发，拖拽、重力、音乐、工作状态和手动动作继续优先。

新增的设置、记忆属性、旧版本、细分情绪、事件消费记录、随机检查时钟和决策记录随原同步协议及 JSON 备份保存。两台设备都需升级，旧客户端不能读取新增字段并会停止同步，不能混用旧版覆盖。召回报告和当前环境原因属于本机诊断，保存在本机档案。中文词表来自 jieba（MIT），保留来源与许可声明；未增加模型或网络检索依赖。

自动历史整理只补记忆，气泡实时互动才改变心情。原插件的参数与界面不等于桌宠现有配置。

全部可读取的本机会话默认纳入整理，不需要逐个选择。「指定一个聊天重点回顾」保留为可选入口，可带入选定聊天的近期用户与最终助手消息。气泡中只显示和企鹅的对话，导入的 Codex 历史可在同步设置中查看。

## 服务器同步

服务器需要 Linux SSH、Python 3 和登录账号自己目录的读写权限。

1. 填写 IP 或主机名、SSH 端口、用户名、密码及宠物存储名。
2. 点「检查连接与指纹」。首次连接需要从可信来源核对 SSH 主机指纹并确认；已知主机直接校验。密钥变化时停止连接，不发送密码。
3. 点「连接并自动同步」。程序在该账号的用户目录自动建立专用数据存储，不安装守护服务、不开放新端口。
4. 另一台电脑填写相同账号及宠物存储名，连接后使用同一个服务器宠物 ID。现有服务器身份优先，本机记忆和近期对话合并进去。

密码只保存到 Windows 凭据管理器，不写入 JSON、备份、日志、进程参数或环境变量。密码留空可使用当前账号已有的受保护密码；没有密码时可使用已经配置的 SSH 代理。连接配置在当前用户的私有应用目录，不属于导出数据。

启动后及运行期间约每 15 秒同步一次，每批最多 250 个变化，并按请求大小分批发送，连续导入的大备份可分次同步。断网保留缓存与待同步队列，显示错误并退避重试；登录、指纹或身份校验失败暂停自动重试，需手动重试或更正配置。不会因为连接失败自动改成本地模式。

两个客户端同时运行时，由服务器串行处理变化，事件 ID 去重；重复请求不重复投喂或增添记忆。活跃设备租约协调自动陪伴，另一台保持状态显示；互动可接管活跃设备。服务器统一计算共享养成状态和心情随时间回稳，避免两台电脑重复累计。窗口坐标、显示器、缩放、落脚、启动及设备设置保持各机独立。

明确点「本地保存」时，当前缓存和待同步变化保留为本机数据；此后不会再自动写入原服务器。重新连接会合并数据。不要通过复制活动 Codex SQLite 或覆盖共享 JSON 来替代同步接口。

## 全部本机 Codex 对话与历史记忆

「采集全部本机 Codex 会话」默认开启；升级时保留原开关。程序自动扫描 CODEX_HOME（未设置时为当前用户的 .codex）下 sessions 和 archived_sessions，不需要先安装 hooks。点「安装 / 更新实时对话联动」可降低新增消息收录延迟，然后在 Codex 按提示审阅并信任新 hooks。未获信任的 hooks 不会运行，自动文件扫描仍可继续。

只采集 UserPromptSubmit 的用户消息和 Stop 的最终助手消息；工具输入输出、推理、子代理消息不进入对话库。常见凭据模式会被遮盖，但仍应避免在聊天中粘贴密码或密钥。近期同步窗口最多 500 条，单条保留脱敏后前 6000 字，陪伴文档总容量 4 MiB；达到总容量时先移除最旧的近期对话，记忆达到容量上限时报告错误。

本机额外保存独立 history.sqlite3 档案及待整理队列，近期窗口淘汰不丢失待学习记录。扫描每轮最多处理四个目录、八个文件和约 4 MiB 数据，大文件分片、游标随事务持久保存，重启续跑；新增文件与追加内容循环发现，文件截断或替换后重新扫描并按消息标识去重。没有 7 天、100 文件或 20 MiB 单文件排除条件。单行超过 1 MiB 或损坏行会记录提示后继续，读取失败保留游标并重试。不同版本的 transcript 格式并非稳定接口，界面如出现损坏/超长行或文件错误，不代表已完整收录。

「立即扫描下一批历史」是手动重试/推进入口，后台会自动持续扫描。气泡及同步页显示已收录、已整理、待整理、已发现文件及待扫描数量。按原始时间处理用户消息；工具、安装指令、推理和子代理不作为用户事实。每条自动记忆附脱敏原话、来源 ID、会话 ID 及时间；同步页可按关键词或「查原文」检索本机档案。助手消息保留为可读对话，不提炼为用户喜好或已完成事项。

全量历史档案与游标保留在采集电脑，不作为活动 Codex 数据库同步；长期记忆、原话依据与来源，以及近期窗口内的原文自动进入现有服务器同步。在 B 电脑可看到 A 电脑整理出的记忆及依据；如果较早原文不在 B 的近期窗口，需要在 A 电脑回查。没有服务器时保存在本机；服务器离线时继续本机学习并排队同步。

ChatGPT 网页、云端聊天和其他没有进入本机 hooks/会话文件的对话，不会因填写服务器而自动被采集。两台电脑分别扫描各自可读取的数据；实时 hooks 联动需要各自信任。服务器上的工作文件或结构化 Codex memory 不等于全部聊天记录，本版不会自动登录远程主机抓取其他账号或平台的聊天。收件队列满会留下提示，不删除未确认记录来伪装成功。

用户明确问到过去的对话或桌宠记忆时，hook 可向 Codex 提供有限的记忆和近期对话快照。快照带时间，不是指令，不把不同会话等同于当前会话；普通工程请求不注入企鹅人格。断网或后台尚未同步时，不能承诺另一台刚刚发生的内容已出现在快照中。

## 导入与导出

- 导出使用专用 JSON 备份，包含版本、SHA-256 校验、宠物状态、长期记忆（含原话依据）、心情及近期窗口，不包含服务器地址、账号、密码或本机窗口布局。
- 先选择备份，界面显示记忆数、对话数及心情，再点「确认导入」。格式、版本或校验失败不覆盖现有数据。
- 导入合并记忆与对话，并恢复备份中的养成和心情。本地模式恢复备份的宠物 ID；服务器模式保留服务器宠物 ID 并将恢复作为待同步事件提交。
- 已遗忘记录保留删除标记，离线旧副本或旧备份不能重新激活同一条已遗忘记忆。备份文件本身可能保留导出当时的内容，需自行管理。
- 全量 history.sqlite3 档案及扫描游标不包含在 JSON 备份中；原始 Codex 会话仍保留，可在原电脑重新扫描。
- 原「旧资料导出」仍保留，其格式与本版完整备份不同，不直接作为本版恢复包。
- 0.9 支持读取 0.7/0.8 完整备份；0.9 的本机档案独立新增，不修改 Codex 源文件。0.8 写入的陪伴状态包含新增字段，回退 0.7 前请保留升级前的数据副本，不要让旧版直接覆盖新版存档。
