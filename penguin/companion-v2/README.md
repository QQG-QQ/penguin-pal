# PenguinPal Companion v2 素材

由内置 imagegen 生成，参考输入为本项目 `penguin-reference-cutout.png`。保留灰色企鹅帽、黑色短发、灰蓝眼睛、青色耳麦、围巾、胸前设备与黄色脚掌。大肥鱼的动作类型和界面结构用于设计参照；本目录没有复制它的角色图片。

## 最终提示词规格

第一张图集：identity-preserve；6 列 × 4 行等大小单元格，真实透明背景，同一角色、比例、服装、柔和日系 Q 版画风，全身完整，无文字、网格、背景、阴影或水印。每格角色居中，站立脚底基线一致。按行顺序生成：

1. 待机、半闭眼、闭眼、左观察、右观察、思考。
2. 开心、摸头柔和表情、摸头闭眼倾身、说话挥手、生气、被戳。
3. 回看尾巴、举小鱼、咬小鱼、向左扫地、向右扫地、蜷卧枕上睡觉。
4. 醒来伸懒腰、被提起悬空、下落、压身落地、坐地眩晕、问好。

第二张图集：identity-preserve；4 列 × 2 行，同一角色的侧前方行走姿态。第一行朝左，第二行朝右，每行四个真实交替步态：前脚接地、经过、反向接地、反向经过。左右独立绘制，固定身体大小和脚底基线，透明背景，不裁切、不加背景或文字。首次请求网络失败，第二次使用内置 imagegen 成功。

## 运行时处理

- 保留原始生成图为 `key-poses.atlas.png` 和 `walking.atlas.png`。
- 切分时在规则网格附近寻找透明分隔行/列，避免生成图片尺寸不是网格整数倍时误裁角色。
- 保留 alpha，按比例缩放至 256 × 256 透明画布，统一脚底锚点；没有用程序重绘角色。
- `manifest.json` 记录每帧尺寸与 alpha 包围盒。播放协议位于 `src/lib/companionAnimation.ts`。
- 32 张帧图被前端实际引用；图集源文件不进入运行时引用。

这是 AI 生成的一致性素材集，步态细节仍应在实际播放中观察。素材自动检查不能代替动作连贯性的目视验收。

## 0.4 挥手补充

内置 imagegen 参考本目录 `idle.png` 生成 `greeting.atlas.png`（4 列 × 2 行），角色挥起右侧鳍袖再放下。完整最终提示词原文见 `greeting-prompt.txt`。切分和归一化得到 `wave-0.png` 至 `wave-7.png`，保留透明通道和 y=244 脚底基线；全套运行时 PNG 由 32 张增加到 40 张。

`greeting.webm` 由这 8 张自己的生成帧编码，256 × 256，7 fps，约 1.143 秒，VP9 + yuva420p。它是逐帧编码的视频，不是 AI 视频模型生成的长动画；没有引入 dsh-pet 原角色或其非商业动画。双视频缓冲播放用于通用 WebM 动画包；当前挥手帧间差异仍可见，不承诺达到参考项目长视频的流畅度。

工作工具为 imageio-ffmpeg 0.6.0 所带 FFmpeg 7.1，仅用于制作，不进入桌宠运行依赖。编码参数：`-framerate 7 -i wave-%d.png -c:v libvpx-vp9 -pix_fmt yuva420p -auto-alt-ref 0 -b:v 0 -crf 28 -an greeting.webm`。内置 PNG 序列是视频被关闭或加载失败时的回退；减少动态使用第一帧。
